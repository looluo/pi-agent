# Repository Notes

## Scope
- This repo is a Tauri desktop wrapper around the vendored Next.js app in `pi-web/`.
- `pi-web/` is a git subtree from `https://github.com/agegr/pi-web.git`; read `pi-web/AGENTS.md` before changing web UI/session behavior.

## Commands
- Root install/build: `npm install`, then `npm run build`.
- Root dev app: `npm run dev` runs `prepare:icons`, `prepare:webapp`, then `tauri dev`.
- `npm run prepare:webapp` copies `pi-web/` to `dist-build/...`, patches that copy, runs `npm ci` and `npm run build` there, then writes `src-tauri/resources/webapp`.
- For focused Tauri checks, run Cargo commands from `src-tauri/` such as `cargo check`.
- For focused web checks, run commands inside `pi-web/`: `npm run lint` and `node_modules/.bin/tsc --noEmit`.

## Build And Generated Files
- Do not edit `dist-build/` or `src-tauri/resources/webapp`; they are generated by `scripts/build-webapp.mjs`.
- `scripts/create-icons.mjs` regenerates `src-tauri/icons/*` before dev/build.
- Root `npm run build` bundles targets from `src-tauri/tauri.conf.json` (`app`, `dmg`, `nsis`) and embeds the prepared webapp through `src-tauri/build.rs`.

## Wrapper Runtime
- The packaged app still requires system Node.js 20+ at runtime; users can override discovery with `PI_AGENT_NODE`.
- Rust starts `webapp/server.js` on a random `127.0.0.1` port, injects `PORT`/`HOSTNAME`, then navigates the hidden Tauri window after the server is ready.
- Native root CAs are exported to an app-data PEM bundle and passed to Node via `NODE_EXTRA_CA_CERTS` and `SSL_CERT_FILE`.
- Embedded assets are cached under the app data `standalone/<cargo-version>-<asset-id>/webapp`; old cache directories are removed on launch.

## Pi-web Patch Points
- Root packaging changes upstream UI behavior in `scripts/build-webapp.mjs`, not directly in the temporary build copy.
- The build script currently changes the page title, injects Tauri `select_directory` browsing into `components/SessionSidebar.tsx`, enables Next standalone output, and applies `patches/pi-web/auto-session-title.patch`.
- If `pi-web` upstream changes make packaging fail, check the exact string markers in `scripts/build-webapp.mjs` before changing Rust or Tauri config.
